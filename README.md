# Youtify — сайт

Сайт для приложения **Youtify** (смесь YouTube Music и Spotify). Стиль и палитра повторяют десктопное приложение: тёмная тема, красный акцент, шрифт Manrope.

## Как открыть

Просто открой `index.html` в браузере (двойной клик). Сборка и сервер не нужны.

При желании можно запустить локальный сервер:

```bash
npx serve .
```

## Что есть

- **Главная страница** с описанием, моком интерфейса приложения и кнопкой «Скачать приложение» (пока открывает окно «Скачивание скоро» — самого файла ещё нет).
- **Регистрация и вход только по никнейму и паролю** — поля почты нет. После регистрации открывается окно «Поставь аватар» (можно пропустить), и сразу открывается раздел «Музыка» — слушать можно сразу. Без регистрации/входа музыка недоступна.
- **Плеер в браузере** после входа: каталог демо-треков, поиск, play/pause, предыдущий/следующий трек, перемотка, громкость, перемешивание, повтор, любимые треки.
- **Поиск как в приложении**: строка поиска на всю ширину, фильтр платформ «Все / Spotify / YouTube Music / Deezer», сетка карточек треков с бейджами источников (S / YouTube / D), лайком и переходом к исполнителю; отдельная страница исполнителя с шапкой, кнопкой «Слушать» и таблицей популярных треков. Разделы сделаны в духе приложения, но в собственном стиле сайта, а не точной копией.
- **Разделы как в приложении**: «Подборка для вас» с обновлением, жанры (Rock, Electronic, Hip Hop, Lo-fi, Pop, Jazz, Трэп, Indie), исполнители с количеством треков. Клик по жанру/исполнителю запускает поиск.
- **Плейлисты пользователя**: готовых подборок нет — в сайдбаре и разделе «Плейлисты» только «Любимые треки» и плейлисты, которые создал пользователь. При создании можно загрузить обложку, позже её можно сменить в плейлисте. Кнопка «+» рядом с треком добавляет его в плейлист; плейлист можно открыть, включить и удалить (кнопка в сайдбаре и в самом плейлисте).
- **Вход по умолчанию**: вошедший пользователь сразу открывает раздел «Музыка», новый посетитель — главную страницу; после успешного входа тоже открывается музыка. Окно входа/регистрации открывается только по кнопке.
- **Аккаунты из приложения**: на сайте есть «Войти через приложение» — он умеет прочитать JSON-файл с аккаунтами и подхватить ники, которые создаст приложение (формат определяется автоматически по различным именам полей). Файл можно выбрать один раз — дальше сайт проверяет его сам при загрузке.
- **Обложки треков**: приходят из Deezer (реальные обложки альбомов), а для демо-заглушек генерируются локально в SVG.
- **Громкость сохраняется** в браузере — после выхода и повторного открытия сайта восстанавливается.
- **Левая панель как в приложении**: бренд, навигация, «Создать плейлист», «ТВОИ ПЛЕЙЛИСТЫ», любимые, «Сейчас играет», аккаунт/настройки/Discord — с теми же классами и стилями, что в Youtify.
- **Главная страница сайтовая**: герой с моком приложения, блок возможностей, кнопка скачивания и подвал.
- Доступ к музыке закрыт для неавторизованных пользователей.
- **Смена темы**: кнопка палитры в шапке переключает готовые пресеты (Классика / Зелёный / Фиолетовый / Оранжевый). После регистрации доступны полные «Настройки темы» с пятью цветовыми полями — такими же, как в десктопном приложении; работают даже без входа. Тема сохраняется в профиле и в браузере.
- **Аватар**: можно поставить при регистрации или позже через меню аватара. Есть редактор, как в приложении: масштаб ползунком и числом в %, колесо мыши приближает, фото двигается зажатой левой кнопкой, плюс ползунки сдвига по горизонтали и вертикали. Готовое фото сохраняется в профиле.
- **Смена никнейма**: пункт «Сменить никнейм» в меню аватара и в сайдбаре музыки. Новый ник сохраняется в профиле и сессии; проверяются длина, допустимые символы и занятость имени.

## Важно

- Аккаунты и любимые треки хранятся в `localStorage` этого браузера. Это демо-режим, не настоящий сервер: пароль хэшируется простой функцией **только чтобы не лежать в открытом виде**. Для реального продукта нужен бэкенд и надёжное хэширование (bcrypt/argon2).
- Музыка берётся через Deezer API (поиск + 30-секундные превью) — полный поток трека в обычном браузере недоступен. Приложение достаёт аудио YouTube Music через встроенный `yt-dlp` и Electron IPC; на сайте этого механизма нет. Для полных треков нужен локальный сервер с `yt-dlp`, который будет отдавать аудио сайту.
- Для поиска используется JSONP-запрос к `api.deezer.com` (обход CORS), обложки — `cover_medium` из ответа. Нужен интернет.
- Чтобы подключить реальный файл приложения к кнопке скачивания, замени в `app.js` обработчик `download-open` на ссылку на `.exe`.
